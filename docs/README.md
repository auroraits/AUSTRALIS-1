# Public docs policy

This directory keeps project-authored public notes and subsystem documentation.

Do not commit vendor PDFs, editable Office documents, customer information
forms, exported decks, or binary copies of external references. Store public
knowledge as Markdown with links/citations, and keep private or third-party
source files outside the public mirror unless redistribution rights are clear.
